DOWN THE HOLE - install it as an app

This folder is a ready-to-upload web app. Once it is on a web address you can install it on your phone, so it has its own icon and opens full screen like any other app. It keeps working offline after the first load, and nothing needs a sign-in to play.

1. Unzip this folder and upload all of its files, unchanged, to any static web host (any "upload a folder" site works). The address has to start with https.
2. Open that address on your phone.
   Android (Chrome): open the menu and tap Install app, or tap the Install app button on the game's start screen.
   iPhone (Safari): tap Share, then Add to Home Screen.
3. Open Down the Hole from your home screen. Choose Play offline for no account at all, or paste an Anthropic API key under AI settings for the full AI.

Your saves stay on the device. To move them between devices, use Transfer & share on the start screen.

Want a real .apk file? Upload this folder first, then use a tool that packages a web app for Android, such as PWABuilder, on your address.
